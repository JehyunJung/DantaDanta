# SagoPalgo 웹 대시보드 요구사항 초안

> 작성일: 2026-05-10  
> 상태: 초안 (draft)

---

## 1. 목적

트레이딩 봇이 서버에서 24/7 실행되는 동안,  
어떤 기기의 브라우저에서도 수익률·포지션·차트를 실시간으로 확인하고  
필요 시 수동 개입(매매 지시)도 가능한 웹 대시보드.

---

## 2. 화면 구성

### 2-1. 대시보드 (홈)
- 총 손익 (금액 + 수익률 %)
- 예수금 / 총평가금액
- 오늘 매매 건수 (매수 N건 / 매도 N건)
- 봇 상태 (실행 중 / 중지)
- 최근 주문 5건 요약

### 2-2. 포지션
- 보유 종목 리스트 테이블
  - 종목명, 보유수량, 평균단가, 현재가, 평가손익, 수익률
- 종목별 수익률 바 차트 (수평)
- 전체 포트폴리오 파이 차트 (종목 비중)

### 2-3. 차트
- 종목 선택 → 캔들스틱 차트
- 지표 오버레이: EMA5/20/60, 볼린저밴드
- 하단: 거래량 바 차트
- 매수/매도 시점 마커 표시

### 2-4. 주문 내역
- 날짜 범위 필터
- 매수/매도 구분 필터
- 테이블: 일시, 종목, 구분, 수량, 단가, 금액, 사유

### 2-5. 스크리너
- 유니버스 종목별 점수 (0~100)
- RSI, MACD, EMA 정배열 여부 시각화
- 뉴스 감성 점수 표시

## 3. 기술 스택

| 구분 | 기술 | 이유 |
|------|------|------|
| API 서버 | FastAPI | 기존 async 코드 재사용, WebSocket 내장 |
| 프론트엔드 | Next.js (React) | 파일 기반 라우팅, 서버 컴포넌트 |
| 차트 | lightweight-charts (TradingView) | 금융 차트 특화, 성능 우수 |
| 기타 차트 | Recharts | 손익/파이 등 일반 차트 |
| 스타일 | Tailwind CSS | 빠른 UI 구성 |
| 실시간 | WebSocket (FastAPI ↔ Next.js) | 현재가 실시간 반영 |
| DB | SQLite (SQLModel) | 주문 내역 로컬 저장 |
