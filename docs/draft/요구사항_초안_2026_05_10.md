# SagoPalgo — 자동 주식 트레이딩 시스템 요구사항 초안

> 작성일: 2026-05-10  
> 상태: 초안 (draft)

---

## 1. 프로젝트 개요

한국투자증권(KIS) Open API를 활용한 자동 주식 트레이딩 시스템.  
제한된 예산 안에서 차트 분석 + 뉴스 감성 분석을 결합해 자동으로 매수/매도.

---

## 2. 핵심 요구사항

### 2.1 자동 매매
- 사용자가 설정한 예산(금액 상한) 내에서만 매수
- 매수/매도 조건을 전략 형태로 정의 (교체 가능한 구조)
- 실시간 가격 모니터링 → 조건 충족 시 자동 주문 실행
- 주문 실패/오류 시 알림 및 재시도 로직

### 2.2 차트 분석 기반 종목 추천
- 기술적 지표 계산: 이동평균(MA), RSI, MACD, 볼린저밴드
- 일봉/분봉 데이터 기반 스크리닝
- 추천 종목 리스트 출력 (점수화)

### 2.3 뉴스 기반 시장 조사
- 종목별 뉴스 수집 (네이버 금융 등)
- LLM을 활용한 감성 분석 (긍정/부정/중립)
- 감성 점수를 매매 전략에 가중치로 반영

---

## 3. 기술 스택 (예상)

| 구분 | 기술 |
|------|------|
| 언어 | Python 3.11+ |
| API 통신 | `httpx` (REST), `websockets` (WebSocket) |
| 데이터 처리 | `pandas`, `numpy` |
| 기술적 지표 | `ta-lib` 또는 `pandas-ta` |
| LLM (뉴스 분석) | Claude API (Anthropic) |
| 스케줄링 | `APScheduler` |
| 설정 관리 | `pydantic-settings` + `.env` |
| 로깅 | `loguru` |
| 저장소 | SQLite (로컬) 또는 PostgreSQL |

---

## 4. 비기능 요구사항

- **안전성**: 예산 초과 주문 절대 불가 (하드 제한)
- **투명성**: 모든 주문/결정 이유 로깅
- **복구 가능성**: 장애 시 포지션 상태 유지
- **모드 분리**: 실거래 / 모의투자 전환 가능
