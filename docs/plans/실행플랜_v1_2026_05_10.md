## Phase 0. 환경 준비 (1~2일)

- [ ] 프로젝트 디렉토리 구조 확정 및 초기화
- [ ] Python 가상환경 설정 (`uv` 또는 `venv`)
- [ ] KIS Open API 앱키/시크릿 발급 및 `.env` 설정
- [ ] 모의투자 계좌 설정 확인
- [ ] 기본 의존성 설치 및 `pyproject.toml` 작성

---

## Phase 1. KIS API 연동 기반 구축 (3~5일)

### 1-1. 인증 모듈
- [ ] OAuth 액세스 토큰 발급 (REST)
- [ ] 토큰 만료 자동 갱신 로직
- [ ] WebSocket 연결 키 발급

### 1-2. REST API 클라이언트
- [ ] 주문 API (매수/매도/정정/취소)
- [ ] 잔고 조회 / 예수금 조회
- [ ] 매수가능 금액 조회
- [ ] 일봉/분봉 차트 데이터 조회

### 1-3. WebSocket 클라이언트
- [ ] 실시간 호가 스트리밍
- [ ] 실시간 체결가 스트리밍
- [ ] 연결 끊김 시 자동 재연결

## Phase 2. 차트 분석 엔진 (3~4일)

- [ ] 기술적 지표 계산 모듈 (MA, RSI, MACD, 볼린저밴드)
- [ ] 종목 스크리닝 로직 (조건 필터링)
- [ ] 추천 점수 산출 알고리즘
- [ ] 추천 종목 리스트 출력

---

## Phase 3. 뉴스 감성 분석 (2~3일)

- [ ] 뉴스 수집 모듈 (네이버 금융 RSS 또는 크롤링)
- [ ] Claude API 연동 — 뉴스 감성 분석 프롬프트 설계
- [ ] 감성 점수 → 매매 가중치 반영 인터페이스

---

## Phase 4. 자동 매매 엔진 (4~5일)

- [ ] 예산 관리자 (Budget Manager) — 하드 상한 제어
- [ ] 전략 인터페이스 정의 (교체 가능한 플러그인 구조)
- [ ] 기본 전략 구현 (이평선 교차 전략)
- [ ] 매매 조건 판단 → 주문 실행 파이프라인
- [ ] 포지션 추적 및 손절/익절 로직

---

## Phase 5. 운영 및 모니터링 (2~3일)

- [ ] 스케줄러 설정 (장 시간 내 자동 실행)
- [ ] 구조화 로깅 (모든 주문/결정 이유 기록)
- [ ] 알림 모듈 (텔레그램 봇 우선)
- [ ] 실거래 / 모의투자 모드 전환

## 디렉토리 구조 (예정)

```
AI-SagoPalgo/
├── docs/
│   ├── draft/          # 초안
│   ├── plans/          # 실행 플랜
│   └── workflow/       # 작업 기록
├── sagopalgo/
│   ├── api/            # KIS API 클라이언트 (REST + WebSocket)
│   ├── analysis/       # 차트 분석, 기술적 지표
│   ├── news/           # 뉴스 수집 + 감성 분석
│   ├── strategy/       # 매매 전략 (플러그인 구조)
│   ├── engine/         # 자동 매매 엔진, 예산 관리
│   ├── notify/         # 알림 모듈
│   └── config.py       # 설정 (pydantic-settings)
├── tests/
├── .env.example
├── pyproject.toml
└── README.md
```
