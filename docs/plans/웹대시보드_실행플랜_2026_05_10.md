## Phase W1. FastAPI 백엔드 (2~3일)

### W1-1. 프로젝트 초기화
- [ ] `web/api/` 구조 생성
- [ ] `pyproject.toml`에 FastAPI, uvicorn, sqlmodel 의존성 추가

### W1-2. 라우터 구현
- [ ] `GET /api/account` — 잔고, 예수금, 총손익

- [ ] `GET /api/chart/{symbol}` — 일봉 OHLCV + 지표
- [ ] `GET /api/screener` — 종목 스코어 리스트

### W1-3. 주문 내역 DB 연동
- [ ] 매매 엔진 주문 실행 시 DB 기록
- [ ] 손익 계산 (매수가 기준 현재가 대비)

## Phase W2. Next.js 프론트엔드 (3~4일)

### W2-1. 프로젝트 초기화
- [ ] `web/frontend/` Next.js 생성 (App Router, TypeScript, Tailwind)
- [ ] `lightweight-charts`, `recharts` 설치
- [ ] API 클라이언트 유틸 (`fetch` wrapper)

### W2-2. 페이지 구현
- [ ] 대시보드 (`/`) — 손익 카드, 봇 상태, 최근 주문
- [ ] 포지션 (`/positions`) — 테이블 + 수익률 바 차트 + 파이 차트
- [ ] 차트 (`/chart`) — 캔들스틱 + 지표 오버레이 + 매매 마커
- [ ] 주문 내역 (`/orders`) — 필터 + 테이블
- [ ] 스크리너 (`/screener`) — 종목 점수 리스트

### W2-3. 실시간 연동
- [ ] WebSocket 훅 (`usePrice`) — 현재가 실시간 갱신
- [ ] 대시보드 손익 자동 갱신 (30초 폴링)

## 기술 스택 확정

```
백엔드: FastAPI + uvicorn + SQLModel(SQLite)
프론트: Next.js 15 (App Router) + TypeScript + Tailwind CSS
차트:   lightweight-charts (캔들) + Recharts (손익/파이)
실시간: FastAPI WebSocket ↔ React useEffect
```

## 실행 방법 (개발)

```bash
# 백엔드
uv run uvicorn web.api.main:app --reload --port 8000

# 프론트엔드
cd web/frontend && npm run dev  # http://localhost:3000
```
