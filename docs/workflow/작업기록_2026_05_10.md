## 2026-05-10 (3)

### Phase 1 완료 — KIS API 연동 기반 구축

**완료된 작업**
- `sagopalgo/api/auth.py` — TokenManager (액세스 토큰 자동 갱신, WebSocket 접속키)
- `sagopalgo/api/rest.py` — KisRestClient (공통 헤더 주입, 401 자동 재시도, KisApiError)
- `sagopalgo/api/websocket.py` — KisWebSocketClient (subscribe/stream, 자동 재연결 10회)

**결정 사항**
- 토큰 만료 5분 전 선제 갱신 (만료 직전 요청 실패 방지)
- asyncio.Lock으로 동시 토큰 발급 중복 방지
- WebSocket 메시지: JSON 제어 메시지와 "|" 구분 시세 데이터 분리 파싱

**다음 단계**
- `.env` 파일 설정 후 실제 토큰 발급 테스트
- Phase 2: 차트 분석 엔진 (일봉/분봉 데이터 조회 + 기술적 지표)
