## 2026-05-10 (3)

### Phase 1 완료 — KIS API 연동 기반 구축

**완료된 작업**
- `dantadanta/api/auth.py` — TokenManager (액세스 토큰 자동 갱신, WebSocket 접속키)

**결정 사항**
- 토큰 만료 5분 전 선제 갱신 (만료 직전 요청 실패 방지)
- asyncio.Lock으로 동시 토큰 발급 중복 방지
- WebSocket 메시지: JSON 제어 메시지와 "|" 구분 시세 데이터 분리 파싱

## 2026-05-10 (4)

### Phase 2~5 완료 — 전체 시스템 구현

**참고 자료**: https://github.com/koreainvestment/open-trading-api (TR ID 및 엔드포인트 확인)

**Phase 2 — 시세 조회 + 차트 분석**
- `api/market.py`: 현재가/일봉/분봉 조회 (FHKST01010100, FHKST03010100, FHKST03010200)
- `analysis/indicators.py`: EMA5/20/60, RSI14, MACD, 볼린저밴드 + 0~100 스코어링
- `analysis/screener.py`: 유니버스 스캔 → 점수 기반 종목 추천

**Phase 3 — 뉴스 감성 분석**
- `news/collector.py`: 네이버 금융 RSS / 종목 뉴스 수집
- `news/sentiment.py`: Claude Haiku 감성 분석 (score -1~1)

**Phase 4 — 자동 매매 엔진**
- `api/order.py`: 매수/매도/잔고/매수가능금액 (실전 TTTC / 모의 VTTC 자동 분기)
- `engine/budget.py`: 예산 한도·종목 비율 하드 차단
- `strategy/base.py`: BaseStrategy 인터페이스
- `strategy/ma_cross.py`: EMA 골든/데드크로스 전략
- `engine/trader.py`: 손절(-5%)/익절(+10%) + 신호→감성필터→주문 사이클

**Phase 5 — 운영**
- `notify/telegram.py`: 주문/오류/일간요약 알림
- `__main__.py`: 평일 30분 간격 스케줄러, 15:35 일간 요약

**다음 단계**
- `.env` 파일 작성 후 모의투자 환경에서 전체 플로우 검증
- 필요 시 추가 전략 구현 또는 유니버스 확장
